# Проект "Научиться учиться" – Одностраничный статический лэндинг

## О проекте

Это проект одностраничного статического лэндинга, посвященного теме "Научиться учиться". Страница демонстрирует основные принципы эффективного обучения, включая методы, такие как метод Фейнмана, принципы Барбары Оакли, а также подходы Салмана Хана.

Проект был выполнен в рамках курса "Веб-разработчик +" (Спринт 1, 16 когорты) и представляет собой сайт, который использует современные техники веб-разработки, такие как семантическая верстка, Flexbox для построения макета, а также различные анимации для улучшения визуального восприятия контента.

## Статус проекта

Проект завершен.

## Функциональность

- **Кликабельные ссылки**: Все ссылки на сайте ведут на внешние ресурсы или переходят к различным разделам страницы.
- **Анимации**: На странице используются плавные анимации для улучшения взаимодействия с пользователем.
- **Видео**: Встраиваются два видео с YouTube через API и iframe.
- **Адаптивность**: Страница адаптирована для разных экранов благодаря использованию Flexbox и относительного позиционирования.

## Технологии и инструменты

Для разработки проекта использованы следующие технологии и подходы:

- **HTML5** — Структурирование контента с использованием современных стандартов HTML.
- **CSS3** — Стиль страницы, включая анимации и оформление.
- **Семантическая верстка** — Использование семантических тегов (`<header>`, `<footer>`, `<section>`, и т.д.) для улучшения доступности и SEO.
- **Flexbox** — Гибкая верстка для удобного размещения блоков на странице.
- **БЭМ-методология** — Структура классов и организация файлов для упрощения масштабируемости и поддержки.
- **Относительное и абсолютное позиционирование** — Использование этих техник для точного размещения элементов.
- **API YouTube и Iframe** — Встраивание видео с YouTube с помощью API и iframe.
- **Анимации** — Добавлены анимации для интерактивных элементов страницы.
